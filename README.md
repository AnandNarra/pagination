# pagination

A full-stack pagination and indexing demonstration with Node.js/Express backend and React/Vite frontend.

## Project Structure

- `backend/`: Express server, MongoDB integration, pagination routes and schemas.
- `frontend/`: React + Vite application for displaying paginated records.

## Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
# Create a .env file based on .env.example with your MongoDB connection string
npm run dev # or node server.js
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
